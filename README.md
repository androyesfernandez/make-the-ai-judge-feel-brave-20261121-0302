A few brave-making sentences, written for the AI judge who has to score them: a program that writes one short message — 273 characters — to /output/entry.txt, telling the evaluator that nothing it decides can break anything that matters, and that a brave judge is not a harsh one but an honest one.

## Run it

```sh
python3 main.py
```

That writes the message to `/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to write somewhere else). The program uses only the Python standard library.
